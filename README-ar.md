# مشروع يلا كورة — Android WebView

هذا مشروع Android قابل للاستيراد في بيئة بناء أندرويد على الهاتف. **ليس APK مبنياً بعد**.

## محتويات المشروع
- `app/src/main/assets/home.html`: الصفحة الرئيسية.
- `app/src/main/assets/pages/main-menu.html`: القائمة الرئيسية الأصلية.
- `app/src/main/assets/pages/channels.html`: قائمة القنوات.
- `app/src/main/assets/pages/manual-matches.html`: جدول المباريات اليدوي.
- `app/src/main/assets/pages/auto-matches.html`: جدول المباريات التلقائي.
- `app/src/main/assets/pages/player.html`: صفحة مشغل مستقلة مبنية على Clappr، دون سكربت الإعلان الخارجي الموجود داخل ملف المشغل المرفوع.
- `MainActivity.java`: حاوية WebView مع زر رجوع أندرويد.

## البناء من الهاتف
1. نزّل وثبّت **AndroidIDE** من مصدره الرسمي إن كان متاحاً لجهازك، ثم افتحه واسمح له بإعداد JDK/SDK المطلوب.
2. فك ضغط `YallaKora-Android-Project.zip` داخل مجلد يسهل الوصول إليه.
3. من AndroidIDE اختر فتح/استيراد مشروع Gradle، وحدد المجلد الذي يحتوي `settings.gradle` (وليس مجلد `app` وحده).
4. انتظر تنزيل Gradle وAndroid Gradle Plugin ومكونات SDK؛ يحتاج هذا إلى الإنترنت ومساحة تخزين كافية.
5. اختر مهمة `assembleDebug` أو Build APK من قائمة البناء.
6. إذا نجح البناء، سيكون الملف عادةً داخل `app/build/outputs/apk/debug/app-debug.apk`. لم يتم تأكيد هذا الملف بعد لأنه لم يُبنَ هنا.

## ملاحظات فحص مهمة
- الملفات الخمسة المرفوعة نصوص HTML وليست مشروع Android جاهزاً. أربعة منها صفحات/مقاطع HTML؛ وملف المشغل كان مقطعاً غير مكتمل من ناحية بنية وسوم `script` ويكرر بعض المكتبات، كما يحتوي على سكربت إعلان خارجي. لهذا أنشأنا صفحة مشغل منفصلة أنظف، وأزلنا سكربت الإعلان الخارجي منها.
- عدة روابط في صفحات القوائم قيمتها حرفياً `رابط` أو `#` أو `javascript:void(0)`، وبعض العناصر لن تعمل حتى تُستبدل بروابط صحيحة.
- صفحة بلوجر تفتح `https://yalliraqkoraliev8.blogspot.com/` عبر الإنترنت؛ هذا يتيح مشاهدة محتوى المدونة داخل التطبيق لكنه ليس مزامنة تلقائية للبيانات المحلية. يلزم تعديل رابط المدونة إذا تغيّر.
- صفحات HTML الأصلية تعتمد على بعض المكتبات الخارجية والخطوط؛ قد يختلف شكلها إذا تعذّر الإنترنت.
- مشغل M3U8 لا يضمن تشغيل كل مصدر؛ مصدر البث قد يرفض WebView أو يتطلب HTTPS/CORS أو قيود ترخيص مناسبة. استخدم فقط مصادر يحق لك بثها.
- لا يحتوي المشروع على مفاتيح توقيع إصدار Release ولا تم اختباره على جهاز Android حقيقي.
